# Documentatie

Kaato speelt alleen nummerkubb. Tot versie 0.4.0 heette de app iKubb en
speelde hij ook klassiek kubb. De werkafspraken voor iedereen die in deze
repo werkt, mens of agent, staan in [`../AGENTS.md`](../AGENTS.md).
